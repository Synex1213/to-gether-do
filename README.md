# 伙伴打卡

一个放在电脑桌面角落的双人近况小窗。各自做事，想起来时看一眼；适合朋友、学习搭子、同事，也可以用于情侣。

## 官网与桌面软件

官网首页用于产品介绍、可交互的示例演示和 Windows 安装包下载。演示使用虚构的“小林”和“阿然”，内容只留在当前页面，刷新或重置后恢复；不读取登录信息，不调用真实状态或任务接口。

- `/`：产品官网，包含桌面场景、七色演示、使用步骤和常见问题。
- `/download/windows`：跳转到 GitHub 最新正式版 Windows 安装包；查询暂不可用时使用已验证的 2.1.0 安装文件。
- `/api/release`：公共版本信息，服务端缓存并合并并发查询。
- `/app/`：保留原浏览器工作区作为兼容入口；官网不引导访客在浏览器内注册或打卡。
- 桌面版继续使用本地 `widget/`，现有账号、配对和任务 API 保持不变。

## 2.0：回到桌面小窗

这版以原始 `couple-widget-upload.zip` 为界面基线。默认不是整页看板，而是 **260×244** 的双人近况卡，首次出现在桌面右下角。收起状态固定为适配现有内容的 260 像素宽度，内部排布保持不变。点「展开」才恢复原来的 **340×560** 小窗，处理状态、计划、互动与设置。拖动标题栏可移动位置，重启后会记住位置。

- 标题栏直接置顶；最小化和隐藏到托盘分别保留。
- 底部七颗色点切换莫兰迪蓝、紫、绿、黄、粉，以及标准黑、白；默认绿色，选择自动保存。
- 底部日历可直接选今天或过去日期，历史计划只读；双方近况始终是最近分享的状态。
- 收起不会清掉尚未提交的状态、任务或回应草稿。
- 使用用户提供的透明击掌图标，标题栏、托盘、快捷方式与安装程序保持同一图形。
- 轻松互动收在详情内，不把抓包次数或长串消息放在常驻视图。

### 2.1：操作更少，状态更准确

- 右键自己的状态行（或聚焦后按 Shift+F10）打开快速状态菜单，最近使用的选项优先显示，无需展开。
- 有效期可选不限、30 分钟、1 小时或 2 小时。右键菜单可临时选本次时长，设置中可调整之后分享的默认值；默认不限。期限保存在服务端，关闭程序不会暂停计时。到期后双方看到“待更新”和上次事项，不会继续显示旧专注状态或允许抓包。
- 拖动结束后靠近边缘会吸附并保留 18 像素边距。设置中可以关闭吸附、锁定位置；托盘菜单也可解除锁定。锁定不影响展开和收起。
- 配对后只出现一次简短操作提示，设置中可重新查看。断网时不重复弹出相同同步提示。

### 2.2：连接与视觉整理

- 请求最多等待 12 秒，读取失败后按退避间隔重试，上限 2 分钟；断网暂停轮询，恢复后重连。写入失败不会自动重复发送。
- 同步中断时保留本次已加载的近况和输入草稿；收起状态只用标题栏小标记提示，展开后提供重试入口。重启后仍需联网加载记录。
- 保留透明原图，改善标题栏、登录页和托盘的显示比例；七种主题提高文字和操作按钮对比度。
- 官网增加同步服务可用性提示和故障说明，改善窄屏阅读。示例与真实同步仍相互隔离。
- 登录防重复提交、注册参数校验、并发用户名冲突处理和服务错误脱敏；生产环境缺少登录密钥时禁止签发令牌。

## 两个人怎么开始

1. 安装桌面程序，各自注册或登录。
2. 一人生成配对码，另一人输入绑定。
3. 默认只看双方近况；点自己的状态行或「展开」可分享当前事项、选择状态和心情。
4. 「计划」中添加、完成自己的事项，或给伙伴的计划留一个回应。点「开始做」可以直接分享正在处理的事项。
5. 不需要时收起；点关闭会隐藏到托盘，从托盘可再次打开或完全退出。

一次仅与一位伙伴绑定。设置中可以解除，再与新伙伴绑定；原关系的计划和回应不会给新伙伴查看。绑定成功会使双方旧邀请码失效。

## 运行与构建

需要 Node.js ≥22.12 与 npm。

```bash
npm ci --include=dev
npm start
```

官网入口为 `http://localhost:3000`；兼容浏览器工作区为 `http://localhost:3000/app/`，与桌面共用 `widget/`。系统置顶、托盘、边缘吸附和位置锁定仅在桌面版生效。开发预览可运行 `npm run dev -- --host 127.0.0.1 --port 4173`。

```bash
npm run desktop
npm test
npm run dist:win
```

Windows 构建产物在 `dist/`，GitHub 的 Windows CI 也会上传安装包。版本号更新合并到 main 后，发布流程会固定版本标签、运行测试，再生成 GitHub Release 与桌面自动更新所需文件；也支持标签触发与手动重试。已发布的版本不会覆盖或移动标签。

默认服务地址为 `https://to-gether-do-2.onrender.com`。旧的无后缀和 `-1` 地址会自动迁移到该地址，用户自定义地址会保留。

## 数据与部署

本地未设置 `DATABASE_URL` 时使用 `pg-mem`，重启后本地预览数据会清空。实际部署使用 PostgreSQL；`NODE_ENV=production` 下缺少连接串或数据库暂时离线时，同步接口返回 503；官网和下载仍可访问，绝不回退到会丢数据的内存库。

Render Web Service：

| 项目 | 配置 |
| --- | --- |
| Branch | `main` |
| Build Command | `npm ci --omit=dev` |
| Start Command | `node src/server.js` |
| Health Check Path | `/healthz` |
| `DATABASE_URL` | 实际 PostgreSQL 连接串 |
| `JWT_SECRET` | 稳定、随机的登录密钥 |
| `NODE_ENV` | `production` |

项目直接读取环境变量，不会自动加载上传软件包中的私有配置。`/healthz` 检查网站进程存活；`/api/health` 单独检查同步就绪状态，数据库不可用时返回 503 与 `sync: unavailable`。正式环境存储应为 `postgres`。数据库恢复后自动重连，无需清空数据或重新注册。`render.yaml` 仍可用于新建 Blueprint。已有手动创建的服务需要在 Render Settings 中同步修改 Health Check Path。

免费数据库有期限，不适合作为长期生产存储。数据库到期、暂停或连接失败时，请先在控制台核实数据库状态和数据保留期限，恢复原实例；不要新建空库覆盖原连接。付费计划、备份和续期由账户所有者确认。

## 结构与验证

| 路径 | 内容 |
| --- | --- |
| `widget/` | 原生桌面与网页共用的小窗界面、主题、日历、草稿与同步 |
| `main.js`、`preload.js` | 原生窗口、托盘与受限的窗口控制接口 |
| `desktop/config.js` | 默认地址、旧地址迁移与外观偏好 |
| `desktop/window-state.js`、`desktop/window-behavior.js` | 小窗尺寸、边缘吸附、锁定与位置保存 |
| `src/` | 账号、配对、计划、状态、回应与轻松互动 API |
| `public/index.html`、`public/website.css`、`public/website.js` | 产品官网和本地示例演示 |
| `public/app/index.html` | 兼容工作区外壳；修改 widget 外壳后运行 `npm run sync:web`，不会覆盖官网 |
| `src/releases.js` | 最新安装包查询、校验、缓存及已验证下载回退 |
| `test/` | 配对隔离、并发加入、主题持久化、收起草稿保留、日历历史及窗口边界检查 |

自动化覆盖接口、DOM 交互与窗口几何规则。Windows CI 验证安装包生成；实际 Windows 桌面置顶、任务栏与安装体验仍需在 Windows 上检查。

服务启动时会为现有状态表补充可空的 `expires_at` 字段，保留已有账号、配对、状态与任务。只改心情不会延长当前事项的有效期；旧客户端分享新状态时会清除旧期限，继续兼容。
