# 2.2 项目复盘

## 定位与边界

伙伴打卡是桌面一对一近况小窗，适合朋友、学习搭子、同事或情侣。默认 260×244，展开 340×560。保留双方状态卡、原透明图标、日历和七种主题，不增加消息流、排行榜或多人关系。官网只承担产品说明、虚构示例和下载。

## 故障根因

本轮检查发现 Render 原免费 PostgreSQL 已到期并暂停，旧程序在数据库初始化成功前不监听 HTTP，因此数据库离线连带官网和下载不可访问。

现将进程存活与业务就绪拆开：`/healthz` 为网站存活，`/api/health` 为同步就绪；HTTP 先启动，数据库连接限时并自动重试。账号和同步接口在故障期间返回 503，公共下载和官网继续服务。生产环境不使用内存库代替原数据库。已有手动创建的 Render 服务已将健康检查改为 `/healthz`。

原数据库仍需账户所有者恢复；在控制台显示的数据保留期内处理，避免删除原库或用空库覆盖连接。付费数据库升级由账户所有者确认。数据库恢复后服务会自动重连。

## 本轮改动

| 部分 | 结果 |
| --- | --- |
| 小窗 | 保持最小尺寸和内部两行布局，连接异常用标题栏标记，详情才显示重试说明 |
| 图标 | 保留原 RGBA 源文件，界面与原生托盘在显示时收紧留白，保持透明 |
| 七色主题 | 提高主要文字与按钮对比度，统一悬停和键盘焦点，扩大主题色点点击范围 |
| 同步 | 12 秒超时，单次定时轮询，失败逐步退避至 2 分钟，恢复网络后重连，失败写入不重放 |
| 登录 | 等待状态、防重复提交、键盘回车、字段标签与自动填充，校验异常类型与长度 |
| 账号安全 | 生产缺少登录密钥时禁止签发令牌；并发重名返回 409；服务器错误脱敏 |
| 官网 | 优化手机阅读、透明图标显示、连接故障说明与真实服务状态，示例不读取账号数据 |
| 依赖与发布 | 更新 Electron/打包依赖，定向升级有漏洞的构建依赖；固定下载文件命名，Windows CI 增加安装后运行目录中的原生窗口启动检查 |

## 验证与局限

自动化测试覆盖接口与配对隔离、状态到期、草稿保留、窗口边界、请求超时与退避，以及生产数据库不可用时官网继续访问。浏览器检查覆盖 260×244、340×560、七色交互和 320/390px 官网，无横向溢出。

Windows CI 负责 NSIS 构建与打包程序原生窗口启动检查。真实 Windows 上的托盘、置顶、安装升级和不同 DPI 下的长期使用仍需实机体验，不能以浏览器模拟替代。原数据库恢复前无法验证生产账号的完整双端同步。
