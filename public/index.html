A FEW LITTLE ANSWERS

你可能
还想知道。

关于这个小小的伙伴空间。

一定要是情侣才能用吗？+

不需要。朋友、学习搭子、同事，或情侣，都可以成为伙伴。产品只约定一对一共享，不限定你们的关系。

网页和桌面软件有什么区别？+

这个网页负责产品介绍、示例演示和下载，不读取你的账号或真实状态。实际配对、打卡和计划共享在桌面软件中进行；系统置顶、边缘吸附和托盘也是桌面版功能。

点关闭后，软件就退出了吗？+

小窗会隐藏到系统托盘，需要时可以重新打开。要完全退出，请在托盘菜单中选择“退出”。

状态会一直显示下去吗？+

可以选择不限、30 分钟、1 小时或 2 小时。设置了有效期的状态，到期后显示“待更新”和上次事项。较久未更新的状态也会标明“上次”，避免被当作当前近况。

可以更换伙伴吗？+

可以。在软件设置中解除当前绑定后，即可重新配对。原关系的任务与回应不会展示给新伙伴。

暂时连接不上怎么办？+

首次启动服务可能需要稍等片刻。网络中断或同步服务暂不可用时，软件会保留已显示的近况和正在输入的草稿，并自动尝试重连；未成功提交的内容不会自动发送。无需反复注册账号。重新打开软件仍需联网加载双方近况。

支持哪些设备？下载在哪里？+

目前提供 Windows 10 / 11（64 位）桌面安装包。页面上的下载按钮会前往 GitHub 官方项目的安装文件；也可以从版本发布页下载。网页可在手机上查看演示，手机不能安装 Windows 程序。
